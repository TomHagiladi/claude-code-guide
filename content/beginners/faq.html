אבטחה ופרטיות

האם הקוד שלי נשלח לענן? האם Anthropic רואה את הקבצים שלי?

▼

כן. Claude Code רץ על המחשב שלכם, אבל כל מה שהוא קורא כדי לעבוד - הודעות, תוכן קבצים, תוצאות פקודות - נשלח לשרתי Anthropic מוצפן בדרך.

מה קורה שם תלוי בסוג החשבון. בחשבון פרטי (Pro / Max) המידע יכול לשמש לאימון המודלים ולהישמר חמש שנים, אלא אם כיביתם את המתג בהגדרות הפרטיות; בחשבון ארגוני (Team / Enterprise / API) אין אימון, והשמירה היא 30 יום. הפרטים המלאים, עם מקורות:

פרטי או ארגוני: מה מגן על המידע שלך

טיפ: קבצים רגישים (סיסמאות, מפתחות API, מידע אישי) שמרו בקובץ .env נפרד ואל תבקשו מ-Claude לקרוא אותם.

האם Claude יכול למחוק לי קבצים בטעות?

▼

כן - לשנות, ליצור ולמחוק קבצים זו אחת היכולות שלו. בדיוק בגלל זה יש בורר מצב שקובע אם הוא עוצר לשאול אותך לפני כל פעולה. במצב ברירת המחדל הוא שואל; במצב תכנון הוא לא נוגע בכלום.

המצבים מוסברים פעם אחת, בשני מקומות משלימים:

  • בורר המצב באפליקציית הדסקטופ - טבלת המצבים ומה לבחור כשמתחילים
  • צעד 4 בפרק "הצעד הראשון" - איך מאשרים ודוחים פעולות בפועל

ורשת הביטחון: /rewind מחזיר קבצים למצב קודם, ופרויקט ב-Git מאפשר לשחזר כל דבר.

האם בטוח להשתמש ב-Claude Code לפרויקטים של לקוחות?

▼

זה תלוי ברמת הרגישות. לרוב הפרויקטים - כן, זה בטוח. אבל כדאי לשים לב:

  • אל תשתפו מידע רפואי, פיננסי או מזהה אישי של לקוחות דרך Claude
  • אל תדביקו סיסמאות, מפתחות API או credentials בשיחה
  • בדקו את מדיניות הפרטיות של Anthropic אם אתם עובדים עם מידע רגיש

עלויות ומגבלות

כמה עולה Claude Code?

▼

Claude Code כלול בכל מנויי Claude - Pro, Max ו-Team - וגם זמין בתשלום לפי צריכה דרך ה-API. המחירים והמכסות המלאים, עם המלצה למי מתאים כל מסלול, נמצאים במקום אחד:

תמחור ועלויות, בפרק "מה זה Claude Code"

מה קורה כשנגמרת לי המכסה?

▼

כשמגיעים למגבלת השימוש, Claude Code ממשיך לעבוד אבל יעבור למודל קטן יותר (Haiku) שהוא מהיר יותר אבל פחות חכם. עדיין אפשר לעבוד, אבל המשימות המורכבות עלולות להיות פחות טובות.

המכסה מתאפסת בתחילת כל חודש. אפשר גם לשדרג לתכנית גבוהה יותר באמצע החודש.

טיפ: השתמשו בפקודה /cost כדי לעקוב אחרי הצריכה שלכם.

מה זה "טוקנים"?

▼

טוקנים הם יחידות המדידה של Claude. חשבו על זה ככה: כמו שמונה מים ליטרים וחשמל בקילוואט - Claude מודד שימוש בטוקנים.

בערך: 1 טוקן ≈ ¾ מילה באנגלית. אז 1,000 טוקנים זה בערך 750 מילים - כמו עמוד וחצי של טקסט.

כל הודעה שאתם שולחים צורכת טוקנים (הקלט), וגם התשובה של Claude צורכת טוקנים (הפלט). ככל שהשיחה ארוכה יותר והקבצים גדולים יותר - נצרכים יותר טוקנים.

איפה הכל נשמר, איך עובדים מכמה מחשבים, ומה לגבי צוותים

איפה Claude Code "יושב" במחשב שלי? מה נשמר ואיפה?

▼

המוח של Claude לא נמצא במחשב שלכם. במחשב יושבת רק "תוכנת לקוח" קטנה (~50-100MB) שעושה שני דברים: שולחת את הבקשות שלכם לשרתים של Anthropic, ומבצעת על הקבצים שלכם את מה שClaud מחליט (קריאה, כתיבה, הרצת פקודות). החשיבה עצמה - הבנת השפה, הגנרציה של קוד - קורית בענן של Anthropic.

הנה כל מה שנשמר לוקאלית במחשב שלכם:

מה איפה (Windows) איפה (macOS / Linux)
הבינארי עצמו %USERPROFILE%\.local\bin\claude.exe ~/.local/bin/claude
הגדרות אישיות %USERPROFILE%\.claude\ ~/.claude/
אישורי כניסה (Credentials) %USERPROFILE%\.claude\.credentials.json macOS: Keychain מוצפן. Linux: ~/.claude/.credentials.json (הרשאות 0600)
היסטוריית שיחות (Sessions) %USERPROFILE%\.claude\projects\<פרויקט>\<session-id>.jsonl ~/.claude/projects/<פרויקט>/<session-id>.jsonl
סקילים, הוקים, פלאגינים אישיים ~/.claude/skills/, ~/.claude/agents/, ~/.claude/plugins/
CLAUDE.md של הפרויקט בתוך תיקיית הפרויקט עצמה - כקובץ רגיל. נשמר ב-git ועובר עם הפרויקט.

נקודה חשובה לאבטחה: קבצי ה-Sessions ב-~/.claude/projects/ נשמרים בטקסט פתוח (plaintext), כולל קוד שClaude קרא ותגובות שלו. הם נמחקים אוטומטית אחרי 30 ימים (אפשר לשנות עם cleanupPeriodDays ב-settings). אם זה מטריד אתכם - הצפינו את הדיסק שלכם (BitLocker ב-Windows, FileVault ב-Mac, LUKS ב-Linux).

מה רץ מקומית ומה רץ בענן?

▼
פעולה איפה רצה
הבנת השפה, חשיבה, יצירת קוד בענן של Anthropic - המודל עצמו לא רץ במחשב שלכם
קריאת הקבצים שלכם מקומית, אבל תוכן הקובץ נשלח לענן כחלק מהפרומפט
הרצת פקודות בטרמינל מקומית במחשב שלכם - Claude שולח את הפקודה, המחשב מבצע
עריכת קבצים מקומית - השינויים קורים ישירות בדיסק שלכם
חיפוש באינטרנט (WebFetch) מעורב - הבקשה יוצאת מהמחשב שלכם, אבל לפני זה Anthropic בודק אם הדומיין בטוח
Claude Code on the Web (claude.ai/code) הכל בענן - הקוד מועתק ל-VM מבודד אצל Anthropic ומורץ שם

איך הנתונים מועברים? כל תקשורת בין המחשב שלכם לשרתי Anthropic מוצפנת ב-TLS 1.2+ (אותה הצפנה כמו בנקאות אונליין). על השרתים - הצפנה ב-AES-256.

האם אני יכול לגשת לעבודה ב-Claude Code ממחשב אחר?

▼

תשובה קצרה: ההיסטוריה של השיחות נשמרת רק במחשב שבו עבדתם. הקבצים של הפרויקט - תלוי איפה הם.

בואו נפרק את זה:

  • המנוי (Pro / Max / Team) - חוצה מכשירים. אתם נכנסים לחשבון מכל מחשב, ויש לכם גישה. /login במחשב חדש = יש לכם Claude Code שם.
  • הקבצים של הפרויקט - תלוי. אם הפרויקט מחובר ל-GitHub (או דרופבוקס/iCloud), הוא נגיש מכל מחשב. אם הוא בתיקייה מקומית בלבד - רק במחשב הזה.
  • היסטוריית השיחות - מקומית! ה-JSONL files של ה-sessions ב-~/.claude/projects/ נשמרים רק במחשב שיצרתם בו את הסשן. --continue ו---resume עובדים רק מקומית.

3 דרכים לעבוד "מכל מחשב"

הדרך איך המגבלות
1. Git + Claude Code בכל מחשב שמרו את הפרויקט ב-GitHub. בכל מחשב חדש: git clone + claude. CLAUDE.md, סקילים פר-פרויקט והוקים נכנסים אוטומטית. היסטוריית שיחות לא עוברת - תתחילו סשן חדש בכל מחשב.
2. Claude Code on the Web נכנסים ל-claude.ai/code מכל דפדפן. הקוד רץ ב-VM של Anthropic. ההיסטוריה נשמרת בענן ומסונכרנת בין מכשירים. לא נוגעים בקבצים על המחשב המקומי - צריך לחבר GitHub. פחות גמיש מ-CLI.
3. Remote Control / --teleport אתם מתחילים סשן במחשב הראשי, ושולטים בו מהטלפון או מדפדפן ממחשב אחר. המחשב המקורי חייב להיות דולק ומחובר לאינטרנט.

פתרון פרקטי לרוב המשתמשים: שילוב של שתי הראשונות - שמרו את הקוד ב-GitHub (גישה מכל מחשב), והחזיקו CLAUDE.md חזק. אם אתם רוצים לראות גם את הסשן הקודם - צריך לעבוד דרך Web בלבד או להישאר על אותו מחשב.

כמה אנשים יכולים להשתמש באותו מנוי? מה לגבי שיתוף פרויקטים בצוות?

▼

מנוי Pro או Max הוא אישי לחלוטין - לאדם אחד. זה לא רק עניין של רישיון אלא של איך המערכת עובדת: כל היסטוריית השיחות, ההעדפות וההגדרות שלכם קשורות לחשבון. שיתוף סיסמה בין כמה אנשים מפר את תנאי השימוש של Anthropic, ובנוסף יוצר בלגן (כולכם רואים את ההיסטוריה של כולם, מנגנון הזיכרון מתערבב, הגבולות נחתכים מהר יותר).

אז מה הפתרון לצוותים?

תוכנית מתאים ל... מה כולל
Claude for Teams צוותים של 2-50 איש כל אחד מקבל מושב (seat) ולוגין משלו. חיוב מאוחד דרך המנהל. גישה גם ל-Claude Code וגם ל-Claude in browser/desktop.
Claude for Enterprise ארגונים גדולים כל מה שיש ב-Teams + SSO (כניסה דרך Google Workspace / Microsoft / Okta), הרשאות לפי תפקיד, מדיניות מנוהלת, ו-Zero Data Retention (Anthropic לא שומרת כלום בשרתים).
Claude Console API צוותי פיתוח שמעדיפים תשלום לפי שימוש המנהל מזמין משתמשים דרך Console. שני תפקידים: "Claude Code" (יוצר מפתחות API ל-Claude Code בלבד) או "Developer" (כל סוג מפתח). חיוב לפי טוקנים.

איך מנהלים גישת צוות?

השלבים הבסיסיים - אותו דבר בכל תוכנית:

  1. בעל המנוי קונה את התוכנית (Teams / Enterprise / Console) ומקבל לוח ניהול.
  2. מזמינים חברי צוות במייל מהדשבורד.
  3. כל חבר מתקין Claude Code על המחשב שלו ועושה claude + /login עם המייל שאליו הוזמן.
  4. שיתוף פרויקטים - דרך GitHub/GitLab. ה-CLAUDE.md, הסקילים פר-פרויקט וההוקים נשמרים ב-repo ועוברים לכל מי שעושה clone.

חשוב להבין: "שיתוף מנוי" ו-"שיתוף פרויקט" הם שני דברים נפרדים. המנוי נצמד לאדם - כל אחד צריך seat משלו. הפרויקט נצמד למקור הקוד - כל מי שיש לו גישה לקוד דרך git יכול לעבוד עליו עם המנוי שלו.

האם הקוד שלי נשמר אצל Anthropic לאימון המודלים?

▼

התשובה המלאה, עם כל ההבדלים בין חשבון פרטי לארגוני ועם מקורות: פרטי או ארגוני: מה מגן על המידע שלך.

זה תלוי בסוג המנוי - וההבחנה הזו חשובה במיוחד אם אתם עובדים עם קוד של לקוחות או IP רגיש.

סוג מנוי ברירת מחדל לאימון תקופת שמירה
Pro / Max (אישי) יש בחירה - צריך לבדוק את ההגדרה. אם אישרתם - הקוד שלכם כן ישמש לאימון. אם לא אישרתם - לא. אם אישרתם אימון: 5 שנים. אם לא: 30 ימים.
Teams / Enterprise / API לא משמש לאימון בשום צורה - אלא אם המנהל הסכים במפורש לתוכנית Development Partner. 30 ימים (ברירת מחדל). Enterprise יכול להפעיל Zero Data Retention - בלי שמירה בכלל.
Bedrock / Vertex / Foundry לא משמש לאימון. המידע נשמר אצל ספק הענן שלכם בלבד. לפי המדיניות של ספק הענן.

לשנות את ההגדרה במנוי Pro/Max: גשו ל-claude.ai/settings/data-privacy-controls ובחרו אם לאפשר שימוש בנתונים לאימון.

אם אתם עובדים עם קוד של לקוחות: מומלץ Teams לפחות - כי שם ברירת המחדל היא "לא לאמן". במנוי Pro תצטרכו לבדוק ידנית את ההגדרה ולוודא שכיביתם אותה. אם המידע סופר-רגיש - חפשו Enterprise + ZDR.

אילו סיכוני אבטחה צריך להכיר?

▼

הנה תמצית הסיכונים שכדאי להיות מודעים אליהם, ומה אפשר לעשות נגד כל אחד:

הסיכון מה לעשות
הקוד שלכם יוצא מהמחשב - כל קובץ שClaud קורא נשלח לשרתי Anthropic. לפרויקטים סופר-רגישים - Enterprise + ZDR. למידע אישי/סיסמאות - שמרו ב-.env ואל תבקשו מ-Claude לקרוא אותו.
היסטוריית שיחות בטקסט פתוח על הדיסק - קבצי JSONL ב-~/.claude/projects/. הצפינו את הדיסק (BitLocker / FileVault / LUKS). או הפחיתו את שמירת ההיסטוריה: cleanupPeriodDays: 7 בהגדרות.
Claude יכול להריץ פקודות מסוכנות - בעיקר במצב bypassPermissions (YOLO). אל תשתמשו ב-YOLO. השתמשו ב-Auto mode עם classifier, או ב-/sandbox להפעלת הוק שמבודד את הקבצים. ראו את שכבת ההרשאות בסעיף "צעד 4".
פלאגין זדוני יכול לעשות נזק - פלאגין הוא קוד שמשתלב בעבודה של Claude. התקינו רק פלאגינים רשמיים (Anthropic, או חברות גדולות מוכרות). למפתחים עצמאיים - קראו את התיאור והקוד לפני התקנה.
שיתוף credentials = בלגן והפרת ToS - מספר אנשים על אותו .credentials.json. אם יש צוות - Teams plan. כל אחד עם לוגין משלו.
מפתח API ישן ב-env vars - ANTHROPIC_API_KEY שנשאר ממקום עבודה קודם דורס את המנוי החדש. בדקו עם /status איזה auth פעיל. אם רואים מפתח API שאתם לא צריכים - Remove-Item Env:\ANTHROPIC_API_KEY ב-PowerShell, או הסירו מ-~/.bashrc.
הזרקת פרומפט (Prompt Injection) - קובץ זדוני שClaud קורא יכול להכיל הוראות מתחזות. אל תאשרו אוטומטית פעולות שClaud מציע אחרי שהוא קרא קוד ממקור לא מהימן. בדקו ידנית פעולות שנראות מוזרות.

פעולות אבטחה בסיסיות שכדאי לעשות פעם אחת:

  1. הצפינו את הדיסק שלכם (BitLocker / FileVault / LUKS) - מגן על קבצי credentials ועל היסטוריית השיחות.
  2. במנוי Pro/Max: בדקו את הגדרת הפרטיות ב-claude.ai/settings/data-privacy-controls.
  3. הריצו /status פעם אחת ובדקו איזה auth פעיל.
  4. הוסיפו .env ל-.gitignore בכל פרויקט עם סודות.
  5. אל תאשרו פלאגין שאתם לא סומכים על מקורו.

שאלות טכניות

האם Claude Code עובד בלי אינטרנט?

▼

לא. Claude Code חייב חיבור לאינטרנט כדי לעבוד. "המוח" של Claude נמצא בשרתים של Anthropic, וכל שיחה דורשת תקשורת עם השרתים האלה. בלי אינטרנט, Claude Code לא יכול לקבל בקשות או לענות.

על אילו מערכות הפעלה Claude Code עובד?

▼

Claude Code עובד על:

  • macOS - תמיכה מלאה
  • Linux - תמיכה מלאה
  • Windows - תמיכה מלאה. עובד ישירות ב-PowerShell וב-CMD ללא צורך ב-WSL. מומלץ להתקין Git for Windows מראש.

בנוסף, אפשר להשתמש ב-Claude Code דרך VS Code (כתוסף), דרך אפליקציית שולחן העבודה, או דרך הדפדפן בכתובת claude.ai/code - כל האפשרויות עובדות על כל מערכת הפעלה.
